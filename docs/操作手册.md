## 1. 这个工具能做什么

这是一个**图形化的安卓设备助手**：把平时需要在黑色命令行窗口里敲的 ADB 命令，变成了点按钮。你可以用它：

| 想做的事 | 用哪个功能 |
|---|---|
| 看设备屏幕（拍下来 / 录成视频） | 屏幕采集 → 📷 截图 / 🎥 录屏 |
| 把设备里的文件拷到电脑 | 文件传输 → ⬇️ 拉取 |
| 把电脑文件放进设备 | 文件传输 → ⬆️ 推送 |
| 查看设备装了哪些应用、启动/停止/卸载应用、安装 APK | 应用管理 |
| 抓取设备运行日志（排查问题给开发看） | 日志抓取 / 实时日志 |
| 直接敲命令（本机命令或设备命令） | 命令行面板 |

**主要对象是电视、盒子等大屏安卓设备**：通过网线或 WiFi 网络连接（见 4.2）。手机、平板也可以用——USB 线直连，或一次性设置后无线连（见 4.3）。可同时管理多台设备。

## 2. 使用前的准备

### 2.1 电脑端

- Windows 10 或 Windows 11。
- 双击打开本工具后**如果窗口一片空白或直接报错**，说明系统缺少 WebView2 组件（精简版系统常见），到这个地址下载安装后再打开：
  https://developer.microsoft.com/microsoft-edge/webview2/
- 正常的 Windows 10 / 11 都自带该组件，无需任何操作。

### 2.2 拿到哪些文件

只需要两个文件，放在**同一个文件夹**里：

```
任意文件夹/
├── adb-log-helper.exe      ← 主程序，双击它运行
└── platform-tools.zip      ← ADB 驱动包（第一次运行时自动安装）
```

说明：

- `platform-tools.zip` 是 ADB 安装包，约 8MB。如果电脑上已经装过 ADB（能直接用 adb 命令），这个文件可以不要。
- 下载地址（在有网的电脑上下载后拷过来即可）：
  https://dl.google.com/android/repository/platform-tools-latest-windows.zip
- 文件名保持 `platform-tools.zip` 不用改；叫 `platform-tools-latest-windows.zip` 或 `adb-tools.zip` 也能识别。
- **文件夹位置随意**，但建议放在非系统盘（如 `D:\ADB工具\`），因为截图、录屏、日志默认都保存在这个文件夹里。
- 整个文件夹可以整体拷贝到别的电脑使用，无需重新安装。

### 2.3 设备端准备：开启 ADB 调试（一次性设置）

**电视 / 盒子（本工具的主要对象）**——在电视的设置里打开 ADB 调试开关。各品牌路径不同，常见的有：

- **通用 Android TV 系统**：设置 → 设备偏好设置 → 关于 → **连点"版本号" 7 次**开启开发者模式 → 返回后出现 **开发者选项** → 打开 **USB 调试**（部分系统叫 **网络调试 / ADB 调试**）
- **小米 / 红米电视**：设置 → 账号与安全 → **ADB 调试** → 设为允许
- 部分电视 / 盒子**出厂就开放调试端口**，没有开关，直接连即可
- 实在找不到时，搜索"**电视品牌 + 型号 + ADB 调试**"

> 电视打开 ADB 开关后，调试端口（5555）一般即自动开放，之后从电脑通过网络连接，**无需任何数据线**。
> 注意：个别电视断电重启后 ADB 开关会自动关闭，连不上时先去检查开关。

**手机 / 平板**（如果也需要连接）：设置 → 关于手机 → **连点"版本号" 7 次** → 返回出现 **开发者选项** → 打开 **USB 调试**。手机用网络连接还需一次 USB 设置步骤，见 4.3。

## 3. 第一次启动：ADB 环境准备

第一次双击 `adb-log-helper.exe` 时，如果电脑上没有 ADB，会出现 **「ADB 环境准备」引导页**，顶部有三个步骤指示：`① 检测 ─ ② 安装 ─ ③ 完成`。

按你的实际情况选择一种安装方式：

### 方式 A：电脑没网，但文件夹里有 platform-tools.zip（推荐）

点 **「开始安装 →」**。程序自动从同目录的压缩包解压安装，**不需要联网**，几秒完成。

### 方式 B：电脑没网，压缩包在别的位置（U盘/其他文件夹）

点 **「选择本地压缩包…」**，在弹出的文件选择框中选中 `platform-tools.zip`，程序自动解压安装。

### 方式 C：电脑能上网

点 **「联网下载安装（约 8MB）」**，程序自动从 Google 官方地址下载并安装，页面有实时进度条。

> 注意：国内网络直接访问 Google 下载地址可能较慢或失败，失败请改用方式 A / B。

安装完成后页面显示 `③ 完成`，点 **「进入主界面 →」** 即可开始使用。

之后再次打开程序**不会再出现这个页面**（ADB 已装好，程序会记住）。

## 4. 连接安卓设备（必读）

### 4.1 核心概念：当前设备

界面上方的 **「设备连接」** 卡片中有一个输入框。**所有功能（截图/录屏/文件/应用/日志）都作用在"当前设备"上**——输入框里显示哪台设备，操作的就是哪台。选中设备后输入框会显示序列号、左侧状态灯，右侧出现 × 清除按钮。

### 4.2 方式一：网络连接（电视 / 盒子，主场景）

电视类设备通过**网线或 WiFi** 接入局域网后，从电脑远程连接，全程不需要数据线：

1. **在电视上打开 ADB 调试开关**（见 2.3，每台电视只需设置一次；已打开的跳过）。多数电视打开开关后调试端口即自动开放。
2. **查电视的 IP 地址**：
   - 电视上：设置 → 网络 → 当前连接的网络（有线 / WiFi）→ 网络状态 / 详情；
   - 或在路由器管理页面的设备列表里找（通常显示"电视"或盒子名称）。
   - IP 形如 `172.31.15.4`。
3. 在「设备连接」的输入框中**直接输入这个 IP**（可带端口，不带默认 5555），点 **「连接」** 按钮或直接回车。
4. 提示连接成功后，设备自动成为当前设备。

要点：

- 电脑和电视必须在**同一个局域网**（连同一个路由器；公司环境注意需要在同一网段/部门网络）。
- 电视**重启或换网络后 IP 可能变化**，连不上时重新查 IP 再连；电视设置里若有"静态 IP / 手动 IP"选项，固定下来以后就不用重查。
- 电视连的是网线还是 WiFi 都可以，对本工具没有区别。

### 4.3 方式二：USB 数据线连接（手机 / 平板）

电视的 USB 口是接 U 盘用的，**不能**用来连电脑；USB 方式只适用于手机、平板：

1. 用 USB 数据线把手机连到电脑（**必须是可以传数据的线**，有些充电线不行）。
2. 手机上弹出 **「允许 USB 调试吗？」** 对话框 → 勾选 **「一律允许使用这台计算机进行调试」** → 点 **允许**。
3. 在工具中点 **「刷新设备」**，或等待 3 秒自动刷新。
4. 点输入框右侧的 **▼** 展开设备列表，点击你的设备即设为当前设备。

**手机转无线连接（可选，拔线使用）**——需要先用 USB 线做一次开启操作：

1. 按上面步骤用 USB 线连上手机并选中它。
2. 在本工具底部面板切到 **「命令行」** 模式，输入下面命令后回车（可以直接复制粘贴）：

   ```
   adb tcpip 5555
   ```

   看到 `restarting in TCP mode port: 5555` 即成功。
   若提示 `more than one device`（电脑连了多台设备），把命令换成
   `adb -s 序列号 tcpip 5555`（序列号在设备列表 ▼ 浮层里能看到）。
3. **拔掉 USB 线**。
4. 查看手机的 IP 地址：设置 → WLAN → 点当前连接的 WiFi，即可看到 IP。
5. 之后按 4.2 的方式输入 IP 连接即可。

> 电视/盒子不需要这一步——打开 ADB 开关后端口就是开的（见 2.3）。

### 4.4 设备列表浮层说明

点输入框右侧 **▼** 展开列表，每行显示：

- **状态灯**：绿色=在线可用；黄色=offline（设备无响应，重新连）；其他=unauthorized（手机上没点允许调试授权）。
- **序列号**：USB 设备是一串字母数字；无线设备是 `IP:5555`；模拟器是 `emulator-xxxx`。
- **连接方式徽标**：USB / TCP / 模拟器。
- **状态中文说明**。

列表每 3 秒自动刷新；点 **「刷新设备」** 立即刷新。

### 4.5 查看设备完整信息 / 断开无线设备

点 **「查看设备与历史」** 打开弹窗：

- 每台设备显示：序列号、连接方式、状态、**设备型号、品牌、安卓版本**。
- 点 **「选为当前设备」** 切换；无线（TCP）设备可以点断开。
- 弹窗下方还有 **最近断开的设备** 记录（最近 3 条），方便快速重连。

### 4.6 切换设备时会发生什么

切换当前设备时，程序自动：停止旧设备的日志抓取、清空应用列表、停止设备 shell 会话（若在命令行面板进入了 `adb shell`）。界面会提示"已切换目标设备"，属正常现象。

## 5. 功能详解：屏幕采集（截图 / 录屏）

操作前先确认上方已选中设备。「屏幕采集」卡片内有两个分段按钮：**📷 截图** 和 **🎥 录屏**，同一时间只显示当前模式的控件。

### 5.1 📷 截图

1. 点 **📷 截图** 切到截图模式。
2. （可选）点 **「选目录」** 自定义保存位置；不选则默认存到程序文件夹的 `screenshots/` 里。
3. 点 **「一键截图」**。
4. 结果显示在底部「操作反馈」里，包含保存的完整文件路径。图片为 PNG 格式，按时间自动命名。

### 5.2 🎥 录屏

1. 点 **🎥 录屏** 切到录屏模式。
2. （可选）点 **「选目录」** 自定义保存位置；默认存到程序文件夹的 `videos/`。
3. 点 **「开始录屏」**，按钮变为停止状态，红点闪烁并显示计时 `mm:ss`。
4. 点 **「停止录屏」** 结束。视频自动从设备回传到电脑，结果与路径显示在「操作反馈」里。

注意事项：

- **单段最长 3 分钟**（安卓系统硬性限制），到时间自动停止并保存；需要更长请分段录制。
- 需要安卓 4.4 及以上。
- 录屏期间**不能同时抓取日志**（两者互用同一条设备通道）：正在录屏时「日志抓取」的开始按钮会变灰并提示"⚠ 录屏进行中，抓取暂不可用"，反之亦然。
- 停止后视频需要几秒钟回传，请以「操作反馈」里的成功提示为准。

## 6. 功能详解：文件传输（拉取 / 推送）

「文件传输」卡片有两个分段：**⬇️ 拉取**（设备 → 电脑）和 **⬆️ 推送**（电脑 → 设备）。

### 6.1 ⬇️ 拉取：把设备里的文件/文件夹拷到电脑

1. 点 **⬇️ 拉取**。
2. **设备路径**：填写设备上的文件或文件夹路径，例如：
   - `/sdcard/DCIM`（相册文件夹）
   - `/sdcard/Download/xxx.pdf`
3. 点 **「选目录」** 选择电脑上的保存位置。
4. 点 **「开始拉取」**。进度与结果（保存到的完整路径）显示在「操作反馈」。

> 设备路径以 `/` 开头（不是 Windows 的 `\`）。常用位置：`/sdcard/DCIM` 相机照片、`/sdcard/Download` 下载、`/sdcard/Pictures` 图片、`/sdcard/Movies` 视频。

### 6.2 ⬆️ 推送：把电脑文件放进设备

1. 点 **⬆️ 推送**。
2. 点 **「选文件」** 选择电脑上的文件（也可手动填路径）。
3. **设备目标路径**：填写要放到的设备目录，例如 `/sdcard/Download/`。
4. 点 **「开始推送」**。

## 7. 功能详解：应用管理

「应用管理」卡片在主界面右侧，包含查询、管理、安装三部分。

### 7.1 查询设备上的应用

1. （可选）在过滤框输入**包名关键字**，如 `weixin`、`com.tencent`。
2. （可选）勾选 **「仅第三方」**——排除系统预装应用，列表更干净。不知道勾不勾就勾上。
3. 点 **「查询应用」**。列表显示包名及每行操作按钮。

### 7.2 管理应用（列表每行右侧按钮）

| 按钮 | 作用 | 说明 |
|---|---|---|
| 启动 | 打开这个应用 | 相当于点击桌面图标 |
| 强停 | 强制停止运行中的应用 | 应用卡死时用 |
| 清缓存 | 清除应用缓存数据 | 不删应用本身 |
| 卸载 | 卸载应用 | ⚠ 有深色弹窗二次确认，确认后才执行 |

### 7.3 安装 APK

1. 卡片底部 **APK 路径**：点 **「选文件」** 选择电脑上的 `.apk` 文件（也可手填路径）。
2. 点 **「安装（-r 覆盖）」**——`-r 覆盖` 表示设备上已有同包名应用时直接升级覆盖（**应用数据保留**）。

## 8. 功能详解：日志抓取

用于把设备的完整运行日志保存成文件（排查问题时发给开发）。

1. （可选）勾选 **「抓取前清空设备日志缓冲」**：只保留本次抓取开始之后的日志，日志更干净。默认不勾（保留之前的）。
2. （可选）点 **「选目录」** 自定义保存位置，默认在程序文件夹的 `logs/` 下；点 **「默认」** 恢复默认目录。
3. 点 **「开始抓取」**。状态提示变为抓取中。
4. 复现你要排查的问题（在设备上操作）。
5. 点 **「结束抓取」**。文件保存路径显示在「操作反馈」里。

日志文件按 `logs/<设备标识>/adb_log_年月日_时分秒.log` 命名，内容包含设备地址、抓取起止时间、完整 logcat 输出。

- 与录屏互斥（见 5.2）。
- 只需"看"日志不需要存文件时，用底部面板的 **实时日志**（见 9.3）更方便。

## 9. 底部面板：操作反馈 / 命令行 / 实时日志

窗口底部有一条固定面板，左侧三个分段按钮切换模式，右侧「清空」和「展开最大 ▴ / 收起 ▾」按钮三模式共用（后者按当前高度自动切换文案，也可拖动上边缘自由调整）。切换到命令行/实时日志时，面板若还在默认高度会自动升到最大（约半屏）；手动拖拽调过的尺寸不会被自动改动。

### 9.1 操作反馈（默认）

所有操作的执行结果带时间戳实时显示在这里。**每次操作之后都看一眼这里确认成功与否**。切到其他模式期间数据继续积累，切回来都能看到。

### 9.2 命令行 ★（进阶功能）

相当于一个内嵌的命令行窗口，可以执行**本机 Windows 命令**（`dir`、`ipconfig`、`ping` 等），也可以执行 **adb 命令**。基本用法：

- 输入命令回车执行，输出直接打在面板里；`↑` `↓` 键翻历史命令。
- `cd` 会记住当前目录；提示符显示当前所在目录。

**进入设备的交互式终端（V1.8.2 新增）**——像直接操作手机一样逐条执行设备命令：

1. 确认上方已选中设备。
2. 输入 `adb shell` 回车。看到提示 `[已进入设备 shell：…]`，提示符变为 `设备序列号 #`。
3. 之后输入的每条命令都在**设备上**执行，例如：
   - `ls /sdcard` —— 列出设备存储根目录
   - `pm list packages | grep tencent` —— 找腾讯系应用包名
   - `getprop ro.build.version.release` —— 查安卓版本
   - `dumpsys battery` —— 查电池状态
4. 输入 `exit` 回车，退回本机命令行模式。

规则与限制：

- 目标设备 = 命令里 `-s 序列号` 显式指定的 > 当前选中的设备；**一台设备都没选但只连了一台**时也可直接进入。0 台或"未选中且连了多台"时会提示先去选设备。
- `adb shell ls /sdcard` 这种**带了后续命令**的写法是一次性执行，不进入交互模式（结果直接返回）。
- 本机命令有 **10 秒超时**：`ping -t` 之类不停输出/交互的命令到时会被终止，面板会注明。
- 设备断开时 shell 自动退出并提示。
- 切换当前设备时，正在进行的设备 shell 会自动停止。

### 9.3 实时日志

像 Android Studio 的 Logcat 一样**实时滚动**显示设备日志（不存文件）。进入该模式**必须先选中设备**，否则会提示并退回操作反馈。

工具栏从左到右：

| 控件 | 作用 |
|---|---|
| 级别下拉（默认 Info） | 只显示该级别及以上的日志：Verbose（全部）→ Debug → Info → Warn → Error → Fatal。切换即生效 |
| 关键字过滤 | 输入即过滤（匹配 Tag 或正文，不区分大小写） |
| 按包名过滤 | 输入**完整包名**回车生效，只看这一个应用的日志（应用需正在运行）；清空后回车取消 |
| 暂停 | 冻结界面方便查看，后台继续记录，恢复后补齐 |
| 清空 | 清空当前显示（会话不停） |
| ⬇ 按钮 | 点亮=自动跟随最新一行；向上翻看时自动熄灭，滚回底部自动点亮 |

日志行按级别着色：灰=V、蓝=D、绿=I、黄=W、红=E、深红=F。界面最多显示 1000 行（高性能渲染，日志洪峰也不卡）。

## 10. 文件都保存在哪里

默认都保存在 **`adb-log-helper.exe` 所在的文件夹**里：

| 内容 | 位置 | 命名规则 |
|---|---|---|
| 截图 | `screenshots/` | 按时间自动命名，PNG |
| 录屏视频 | `videos/` | 按时间自动命名，MP4 |
| 抓取的日志 | `logs/<设备标识>/` | `adb_log_20260623_150405.log` |

以上目录（截图/录屏/日志）均可在操作时点「选目录」改为其他位置。

## 11. 常见问题（FAQ）

**Q1：双击 exe 后窗口空白 / 报缺少 WebView2？**
系统缺少 WebView2 组件（常见于精简版/LTSC 系统）。到 https://developer.microsoft.com/microsoft-edge/webview2/ 下载 Evergreen Runtime 安装后重开。

**Q2：电视连不上（输入 IP 后提示连接失败 / connection refused / 无法连接）？**
按顺序检查：① 电视的 **ADB 调试开关**是否打开（见 2.3；部分电视断电重启后开关会自动关闭，需重开）；② IP 是否正确——电视重启/换网络后 IP 可能变了，重新在电视 设置→网络 里查看；③ 电脑和电视是否在**同一个局域网**（公司环境常按部门划分网段，跨网段连不上属正常，需找网络管理员）；④ 电视若休眠/待机，网络可能断开，先唤醒再连；⑤ 用本工具命令行执行 `ping 电视IP` 看网络是否通。
仍连不上时，在命令行执行 `adb connect 电视IP:5555`，把提示内容发给管理员或开发排查。

**Q3：手机 USB 插上了，设备列表里没有？（手机/平板场景）**
按顺序检查：① 数据线是否支持传数据（换一根试试）；② 手机是否弹出了"允许 USB 调试"并点了允许（下拉通知栏里也能看到）；③ 手机上 USB 连接模式选"传输文件 (MTP)"而不是"仅充电"；④ 点「刷新设备」。仍不行，换 USB 口（避免 USB Hub）。

**Q4：设备显示 unauthorized？（手机/平板 USB 场景）**
手机屏幕上应弹出了调试授权框，勾选"一律允许"并点允许；没弹的话拔插一次数据线，或在开发者选项里点"撤销 USB 调试授权"后重插。

**Q5：电视上到底哪里开 ADB 调试？**
各品牌路径不同，见 2.3 的常见路径列表；找不到时搜索"电视品牌 + 型号 + ADB 调试"。部分电视/盒子出厂即开放端口，无开关可直接连。

**Q6：命令行里输入 adb 提示"不是内部或外部命令"？**
本工具从 V1.8.1 起已自动处理此问题。若仍出现，说明用的是旧版程序，请更新到 V1.8.1 及以后版本。

**Q7：输入 `adb shell` 后没反应？**
V1.8.2 起裸 `adb shell` 会直接进入交互终端（提示符变为 `设备 #`）。若提示进入失败：一台设备都没选且连了多台时，会提示先在「设备连接」中选择目标设备；选中后再试。旧版本程序无此功能，请更新。

**Q8：交互 shell 里命令没输出？**
命令确实在设备上执行后才有输出；`ls` 无参数时列当前目录。若设备已断开，会话会自动退出并提示，重新连接设备后再进。

**Q9：录屏为什么最多 3 分钟？**
安卓系统 `screenrecord` 命令的单次硬性上限，工具无法突破；需要长录制请分段录，或用设备自带的屏幕录制功能。

**Q10：录屏/日志抓取按钮是灰的点不了？**
两者互斥（共用设备通道）：录屏中不能抓日志，抓日志中不能录屏。结束当前操作即可。

**Q11：卸载/清缓存时弹出的深色对话框是什么？**
危险操作的二次确认，防误点。仔细读文字，确认要执行才点确认。

**Q12：日志文件太大，怎么看？**
用记事本/VS Code 打开，按时间定位（文件头有抓取起止时间）；或改用「实时日志」的级别/关键字过滤在线看。

**Q13：换一台电脑能用吗？**
把整个文件夹（含 exe 和 platform-tools.zip）拷过去即可；新电脑第一次运行会重新安装一次 ADB（几秒）。若新电脑缺少 WebView2，按 Q1 处理。

**Q14：程序会修改我电脑的什么设置？**
仅在安装 ADB 时把 `adb-tools` 目录加入**当前用户**的 PATH 环境变量（好处：你自己在命令行里也能直接用 adb）。不写注册表其他位置、不改系统设置。
