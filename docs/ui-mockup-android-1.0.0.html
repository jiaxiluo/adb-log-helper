设计要点（对应需求 REQ-A1/A2/A3）

  1. 一屏三卡：连接 → 装 APK → 抓日志，现场动作从上到下走完，无需翻页。
  2. 置灰联动：未连接设备时下两张卡置灰（对应桌面版联动逻辑）。
  3. 历史直连：手机上敲 IP 麻烦，最近连接的设备点一下即连，行尾 × 删除。
  4. 安装失败中文化：选 test_v1.0.apk 可看效果——版本降级/签名不一致等设备端报错翻译成人话。
  5. 两键式抓取：「开始抓取 → 结束并分享」，结束即拉起分享面板（微信/钉钉），现场抓完直接发回去。
  6. 后台保活：抓取中退到后台/息屏不中断，由前台服务保障。
  7. 断开设备时：若正在抓取，自动停止并保存，不丢已抓内容。
